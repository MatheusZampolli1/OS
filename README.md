# Orçamento Falado

Página para prestadores de serviço de obra (pedreiro, pintor, eletricista, encanador): você fala o serviço, os itens aparecem montados e sai um orçamento em PDF com fotos, sinal via Pix e campo de aceite, pronto para mandar no WhatsApp. Também gera recibo e guarda a lista de orçamentos com status (enviado, aprovado, pago).

- Tudo roda no navegador; os dados ficam só no aparelho de quem usa.
- O reconhecimento de fala usa a Web Speech API (melhor no Chrome para Android) e precisa de https.
- O Pix segue o padrão BR Code (copia e cola estático) do Banco Central.
